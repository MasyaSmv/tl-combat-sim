# Приближённая историческая модель

Это авторский JS-снимок предварительного исследования, сохранённый до будущей реализации Go. Он не зависит от Google Таблиц: адаптер SpreadsheetApp исключён. Это не самостоятельная рекомендуемая библиотека и не доказанная спецификация TL.

```text
node research/legacy/check.cjs
```

Требуется Node.js с поддержкой используемого современного JS. Зависимостей из npm и сети нет. Команда проверяет пять синтетических свойств исходного движка, воспроизведение приближённого сценария и 13 числовых наблюдений.

`scenario.json` содержит использованные входы и исторический expected total, помеченный `approximate-legacy-snapshot-not-game-ground-truth`. Сравнение total подтверждает лишь воспроизводимость снимка. Оно не доказывает игровые формулы, полный DPS или точность нового Go-ядра.

Ключевые ограничения: нет автоатак/парной атаки и дополнительных снарядов Природы, неполная Отрешённость, приближённые стаки и условия пассивок, неизвестная защита цели, условное накопление Метки и снимок DoT. Время ряда применений 0.32 с и время Перста 1.79 с не измерены. Старый mode ожиданий нельзя слепо переносить через нелинейные взаимодействия.

Функции возвращают числовой журнал и список применений. Поскольку результат частичный, реальный полный DPS может отличаться в обе стороны. Обновление точной механики не должно подгоняться ради сохранения legacy-total.
