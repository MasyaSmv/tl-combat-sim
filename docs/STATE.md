# Состояние проекта

Обновлено: 26.10.2026. Этап: M0 — документация и подготовка доказательств.

## Решения владельца

- Отдельный Go-пакет, которому передаются данные; сервер и сайт не обязательны для расчёта.
- Цель: сравнение билдов/ротаций для владельца и друзей, затем возможное предложение интеграции tl-build.ru.
- Репозиторий публичный. Контакт с разработчиками сайта пока не выполнялся и не поручен.
- Начальная пара оружия: арбалет + книга/жезл, Fury, текущая специализация Перста вместо Круга из старого руководства.
- Нейросеть не является расчётным ядром.

## Реально подготовлено

- README, проектные правила, архитектура, план, реестр неопределённостей, обзор аналогов.
- 13 наблюдений тиков из двух пользовательских записей; 4 из первой и 9 из второй. Малые последние прибавления отделены от полных тиков.
- Снимок текущих использованных статов и исследовательского сценария.
- Legacy JS-модель и планировщик из предварительного расчёта; они не выдают доказанный полный DPS.

## Ещё НЕ реализовано

Go-модуль, Go-API, событийный каркас на Go, полные игровые формулы, все проки, Monte Carlo, оптимизатор, HTTP API, импорт tl-build.ru, веб-интерфейс. Наличие описания метода Simulate в README не означает наличие метода в коде.

## Ближайшая задача: M1.1

Создать минимальный Go-модуль с контрактами и синтетической очередью событий.

1. Проверить доступный стабильный Go toolchain и зафиксировать выбранную минимальную версию. Не копировать версию из старого WoWSims README.
2. Уточнить типы времени, числовой формат урона, ошибки валидации и описание неопределённостей.
3. Реализовать только стабильный порядок событий, границу боя и контекст отмены на синтетическом сценарии.
4. Добавить содержательные тесты и короткий пример запуска. Не портировать весь legacy-код без аудита.
5. Обновить STATE с выполненными командами; после этого перейти к откатам и баффам M1.2.

Критерий готовности M1.1: воспроизводимый журнал синтетического сценария, одинаковый порядок совпавших событий, корректное завершение/отмена и отсутствие непредусмотренных side effects.
