# 0001 — сначала независимый Go-пакет

Дата: 26.10.2026. Статус: принято по обсуждению с владельцем.

## Контекст

Ручной расчёт Fury вырос из Google Таблицы и приблизительной JS-модели. Владелец хочет передавать билды друзей и потенциально предложить компонент tl-build.ru. Важны проверяемость и работа без привязки к таблице/интерфейсу.

## Решение

Реализовать библиотеку на Go. Входы и правила задаются явно; API/CLI/UI и оптимизатор будут потребителями пакета. Сначала синтетический каркас, затем проверка одного навыка и только после неё взаимодействия Fury. Репозиторий публичный по отдельному сообщению владельца.

Не обучать нейросеть как источник численного ответа. Не переписывать всю приближённую JS-модель как достоверные игровые формулы. Сохранить legacy отдельно для истории и воспроизводимости.

## Альтернативы

Продолжать только в таблице — удобно для небольших экспериментов, но не решает независимый пакет. Python удобен для анализа замеров, однако владелец принял направление Go. Ближайший найденный TL-Helper интересен архитектурой, но его игровой pipeline не завершён и он не является нужным Go-пакетом.

## Последствия

Появляется работа по формальным контрактам, тестам и данным каждой механики. Полная поддержка всех классов и интеграция с сайтом не обещаются до проверки первого игрового среза. Лицензия будущего распространяемого пакета ещё требует отдельного решения; сторонний код не импортирован.
