# Реестр механик и неопределённостей

Статусы: `observed` — непосредственно прочитанные числа/события; `calibrated` — параметр подобран при указанных условиях; `hypothesis` — рабочее правило; `unsupported` — нет достаточной реализации/доказательства. В будущем к статусам нужны evidence IDs и game-build scope.

| Механика | Текущее основание | Что ещё требуется |
|---|---|---|
| Полные тики и малое завершение | observed, CSV двух записей | Точный серверный timer и округление; интервалы не задавать по одному последнему числу |
| Крит DoT ×1.09 без снаряжения | Отношения тиков совместимы; исходы inferred | Независимые флаги исходов и проверка на новых записях |
| Мощный DoT ×2 | Отношения совместимы | Проверка исходов и стадий применения сопротивлений |
| База книги 179–493 в старой модели | Снимок прежнего исследования | Актуальный отдельный экран книги и условия динамических прибавок |
| Белая книга | unsupported для точного диапазона | Не использовать строку вспомогательного урона арбалета как книгу |
| +56.8% recovery | observed stat, деление отката на 1.568 — hypothesis | Проверить точный момент начала/сокращения и отдельные исключения |
| +49.8% buff duration | observed stat; ×1.498 для выбранных баффов — hypothesis | Не распространять автоматически на все эффекты и DoT |
| Свет +92 max / Час +220 SDB | Описания выбранной специализации | Начальный удвоенный эффект, фактическое применение и snapshot |
| Касание 41%+37 на стак | Описание; до 3 стаков | Стаки +1/+2, refresh, добавка длительности при cap и корреляция исходов |
| Перст 85%+95 / прямой 260% | Описание текущей специализации | Время применения; наследование оружейных бонусов, если есть |
| Перст и поле Круга | Поле в текущем расчёте НЕ наследуется | Отдельно доказать, прежде чем исполнять повторные наложения |
| Метка 40% накопления | hypothesis | Допустимые источники, self-exclusion, повторная детонация и особые исходы |
| Взрыв остатка DoT | hypothesis; порядок PDF | Snapshot, сопротивления, снятие эффектов, повторный крит/heavy, момент срабатывания |
| Злой рок после Слова до detonation | Руководство PDF стр. 15 | Актуальные окна и воздействие на каждый тип проклятия |
| Отрешённость | Legacy: только −0.36 с за наложение | −0.072 по стакам, лимиты/сек, .05 продления, все триггеры/исключения |
| Миазмы/Старец | Legacy использует приближения | Время жизни, refresh, стадии множителей и условия успешного ослабления |
| Дар 36% ×1.2, mastery 5%/15% | Описания выбранного билда | Независимая проверка совместного порядка и применимости |
| Автоатаки/парная атака/Природа | unsupported в сумме legacy | Полные механики, расписание и влияние на прочие проки |
| Вердикт Бездны, Аспид, Лепестки, Небесная кара | unsupported | Вероятности, ICD, допустимые источники, ограничения рекурсии |
| Уязвимая точка/контратака блока | Условные действия | Нужны события босса; на манекене не включать автоматически |

## Ошибки, которых нельзя повторять

- Добавить второй раз 15%/10% комплектного крита к уже показанным 34%.
- Добавить мастерство +100 к экранному рейтингу, который уже включает близкую цель.
- Считать повышение восстановления 56.8% вычитанием 56.8% из отката.
- Продлить DoT на 49.8% как положительный бафф.
- Считать каждое изменение HP отдельным попаданием при плавной интерполяции интерфейса.
- Принять суммарную потерю HP за чистый DoT при наличии отдельных попаданий/счётчиков.
- Принять совпадение отношений тиков за доказательство всех формул или полного DPS.
- Записать неучтённый эффект как физически нулевой урон и назвать сумму доказанной нижней границей.
